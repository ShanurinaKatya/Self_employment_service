# Лабораторная работа №2 Calculator JavaScript
**Цель** лабораторной работы - знакомство с интрументами построения пользовательских интерфейсов web-сайтов: HTML, CSS и JavaScript. В ходе выполнения работы необходимо продолжить реализовывать простой калькулятор.\
**План** работы:
1. Программирование логики с помощью JavaScript
2. Программирование кнопок калькулятора
3. Запуск калькулятора с помощью LiveServer
4. Задание по варианту
