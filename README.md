# Лабораторная работа №1 Calculator HTML/CSS
**Цель** лабораторной работы - знакомство с интрументами построения пользовательских интерфейсов web-сайтов: HTML и CSS. В ходе выполнения работы необхаодимо ознакомиться с кодом реализации простого калькулятора\
**План** работы:
1. Изучение основ HTML и CSS
2. Создание проекта
3. Верстка калькулятора
4. Стилизация калькулятора с помощью CSS
5. Задание по варианту
